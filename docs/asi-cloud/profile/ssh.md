---
title: SSH keys
id: ssh
---

In order to connect to any VMs that you deploy you will need to specify an SSH key to be added into it, that you will use to connect to the machine.
You can save your SSH keys in this section of your profile, so that you see all of them every time you create a new VM and can easily choose which ones you want to add to the machine.

The default key is the one that is preselected by default when going into the machine creation page.
You can also give a name to your SSH keys for convenience, especially if you give or manage access for other people.
