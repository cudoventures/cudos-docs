This page is the main profile section where you can manage personal information, communication preferences and more.

![profile_settings](@site/static/img/profile-settings.png)

You can add contact methods to receive alerts, notifications and newsletters, manage your identities, and change your login password if you have one.

## Template variables

In the Template default variables tab you can also save variables that are used in some popular [templates](/docs/asi-cloud/usage/via-user-interface/templates/templates-overview) so that you don't have to manually input them every time you deploy a new machine with them.
